# gEngine

gEngine は、省メモリと大量オブジェクトの効率的な処理を目指すゲームエンジンの開発プロジェクトです。独立した gLang のコンパイラーと gVM、描画・音声等のコンポーネントを組み込みます。

**gEngine Ver.0.1.0** は Windows x64 用です。Qt Widgets を使う Windows 用 Editor からプロジェクトの作成・開閉、非同期コンパイル、診断表示、取消しを行えます。コンパイルした VM の読込み・一回実行・リセットと、2D / 3D 集合の読み取り専用表示にも対応します。実行予算・読込み時のメモリ上限を指定し、VM のメモリ内訳と表示用コピーの費用を確認できます。同じ操作をローカルの MCP 接続でも使えます。保存済みシーンからのビルド、pack 作成、実行物配置、別プロセスの GameRunner の起動・終了管理にも対応します。PIE の計測パネルと GameRunner の JSON 出力で、処理時間の分布、VM・描画・音声の保持量、プロセスの使用量を確認できます。

2D / 3D サンプルを単独の GameRunner と Editor 埋め込み型 PIE で実行できます。両次元の初期配置・ゲーム設定・カメラを GUI と MCP で編集し、Undo / Redo、保存・再読込み、編集プレビューを使えます。ビューでは対象の選択、移動ハンドル、クリック配置・削除、パン・ズームを使えます。3D は XYZ 軸の移動と編集用カメラの回転にも対応します。保存したシーンは GameRunner でも直接起動できます。サンプルは通常ファイルと BinPackLib の pack から、同じモジュール・シーン・描画素材・効果音を読み込めます。素材原本を保った登録、対象への描画・音声素材の割当て、参照切れの診断と修正にも対応します。言語・VM は `components/gLang` の独立リポジトリで管理し、gEngine は採用コミットを固定して使います。

gEngine と gLang の版は別に管理します。採用する gLang は Ver.0.2.0 で、基本 4 型・ベクトル・構造体・固定容量集合・一括更新・列ビュー・state・import と C++ 接続に対応しています。採用した 4 部品のソースを用意すると、MSVC でビルドできます。[ビルド手順](docs/user/README.md#editor-をビルドして起動する) を参照してください。
