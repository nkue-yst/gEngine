# gLang と gVM

gLang と gVM は `components/gLang` の独立コンポーネントです。構文・型・実行制限・C ABI・C++ 簡易 API の正本は、[gLang の利用者向け仕様](../../components/gLang/docs/user/language-and-vm.md) を参照してください。

単独のビルド・実行は [gLang の README](../../components/gLang/README.md) に従い、`components/gLang` を作業ディレクトリとして実行します。gEngine は固定した同じ gVM をソースから組み込みます。
